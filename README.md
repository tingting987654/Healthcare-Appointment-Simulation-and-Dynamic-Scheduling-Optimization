# Healthcare-Appointment-Simulation-and-Dynamic-Scheduling-Optimization

# Healthcare appointment scheduling is a fundamental operational problem in service systems with fixed capacity and uncertain demand, in which healthcare providers must allocate limited appointment slots while balancing multiple objectives.

# This study investigates a simplified healthcare appointment system with different patient groups. Basic assumptions of this system are as follows:
#   1) All patients are either urgent (U) patients or routine (R) patients.
#   2) Arrivals of each patient type are modelled as independent Poisson processes with respective arrival rates.
#   3) Appointments are allocated immediately upon arrival.
#   4) Each working day contains 6 predefined appointment slots.
#   5) The long-run performance of scheduling policies is evaluated by Monte Carlo simulation.

# The study evaluates all scheduling policies, with the results structured around the main questions:
#   1) The First Available Slot (FAS) policy is evaluated in Q2.
#   2) In Q3, FAS is extended by the workload-based delay mechanism.
#   3) In Q4, FAS is extended by on-call routine patients (OCR) and the workload-based reservation mechanism.
